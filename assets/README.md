# assets

**`header.jpg`** is the photo band behind the "braidbabes Waitlist" logo on both
customer screens.

It's already in place — exported from `bb header.png`, resized to 1200 px wide
and saved as JPEG (4.4 MB → 167 KB) so it loads fast on phones over event wifi.

To swap it: drop in a new `header.jpg`, ideally around 1200 px wide. It's
cropped to fill, centred. The image is drawn with no overlay on top, so whatever
shading it needs should be baked into the file itself.

If the file is ever missing the band falls back to a pink gradient — nothing
breaks.
